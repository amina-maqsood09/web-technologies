Try it before you check it

Reading is only half of learning. Attempt each challenge first, then open the hint or the answer.

Challenge: split the URL

Name each part of this address.

https://www.example.com:443/courses/web?id=101#http
Show hint

Look for the symbols ://, :, /, ? and #. Each one starts a new part.

Show answer
  • scheme https://
  • subdomain www
  • domain example.com
  • port :443
  • path /courses/web
  • query ?id=101
  • fragment #http

Challenge: read the status

A browser asks for a page that does not exist. Which status code group does the server answer with, and what is the common example?

Show hint

The mistake is on the client's side: the address was wrong.

Show answer

The 4xx group (client errors). The common example is 404 Not Found.
