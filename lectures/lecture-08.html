Lecture 8: Effects, Animations and Responsive CSS

Gradients, transforms, transitions, animations and media queries

Summary

This lecture explains how to polish a page and make it responsive. You will learn rounded corners, gradients, opacity, transforms, transitions, keyframe animations, web fonts, custom properties and media queries.

Topics Covered

  • Visual effects
    • border-radius, linear-gradient and box-shadow
    • opacity makes the whole element transparent, rgba() only a colour
  • Transforms
    • translate, rotate, scale and skew
  • Transitions and animations
    • transition: property duration timing-function delay
    • @keyframes with animation-name, duration and iteration-count
  • Web fonts and variables
    • @font-face loads a font file
    • Custom properties: --name and var(--name)
  • Media queries
    • @media applies styles for certain screen sizes
    • @supports checks browser support
Effects and Properties
Effect Property Example
Rounded corners border-radius border-radius: 12px
Gradient linear-gradient() linear-gradient(90deg, red, blue)
Move or scale transform scale(1.1)
Smooth change transition transition: transform 0.3s
Keyframe animation animation animation: pulse 1s
Screen size rule @media @media (max-width: 600px)

Example Code

A hover transition, a gradient, a keyframe animation, a custom property and a media query.

<style>
  :root { --demo-color: #1f4e8c; }
  .btn8 {
    padding: 12px 24px;
    border: none;
    border-radius: 8px;
    background-color: var(--demo-color);
    color: white;
    transition: transform 0.3s ease;
  }
  .btn8:hover { transform: scale(1.1); }
  .gradient8 {
    margin: 16px 0;
    padding: 16px;
    border-radius: 12px;
    background: linear-gradient(90deg, #14305a, #4a90d9);
    color: white;
  }
  .pulse8 {
    width: 50px;
    height: 50px;
    background-color: var(--demo-color);
    animation: pulse8 1s ease-in-out 3 alternate;
  }
  @keyframes pulse8 {
    from { transform: scale(1); }
    to { transform: scale(1.4); }
  }
  @media (max-width: 600px) {
    .gradient8 { background: crimson; }
  }
</style>
<button class="btn8">Hover over me</button>
<div class="gradient8">A gradient box with rounded corners (turns red on small screens).</div>
<div class="pulse8"></div>

Output

A gradient box with rounded corners (turns red on small screens).

Try It Yourself

Hover over the button, then change the color or the speed.
