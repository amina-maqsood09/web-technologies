Lecture 7: Positioning, z-index and Floats

Normal flow, positioning, stacking and floats

Summary

This lecture explains how the browser lays out elements by default and how to move them. You will learn normal flow, the position property, the z-index stacking order, floats, clear and the clearfix.

Topics Covered

  • Normal flow
    • Block elements stack vertically, inline elements run along the line
    • position: static is the default
  • Positioning
    • relative, absolute, fixed and sticky
    • top, right, bottom and left offsets
    • An absolute element is placed against its nearest positioned ancestor
  • z-index
    • A higher z-index is closer to the viewer
    • Stacking contexts group layers
  • Floats
    • float: left or right makes text wrap around an element
    • clear stops wrapping
    • The clearfix gives a parent its height back
  • Common pitfalls
    • Using fixed for everything
    • Fixed heights that cause overflow
Position Values
Value Behaviour
static Normal flow (the default)
relative Moved from its normal place, original space is kept
absolute Removed from the flow, placed against the nearest positioned ancestor
fixed Placed against the viewport and stays when scrolling
sticky Scrolls normally, then sticks at an offset

Example Code

A relative card with an absolute badge, and a floated square with a clearfix.

<style>
  .card7 {
    position: relative;
    width: 260px;
    height: 90px;
    padding: 12px;
    background-color: #e8f0fb;
    border: 2px solid #1f4e8c;
  }
  .badge7 {
    position: absolute;
    top: 8px;
    right: 8px;
    z-index: 2;
    padding: 2px 8px;
    background-color: crimson;
    color: white;
  }
  .square7 {
    float: left;
    width: 60px;
    height: 60px;
    margin-right: 12px;
    background-color: #1f4e8c;
  }
  .clearfix::after {
    content: "";
    display: block;
    clear: both;
  }
</style>
<div class="card7">Relative card <span class="badge7">New</span></div>
<div class="clearfix" style="margin-top: 16px;">
  <div class="square7"></div>
  <p>This text wraps next to the floated square. The clearfix keeps the parent tall enough.</p>
</div>
