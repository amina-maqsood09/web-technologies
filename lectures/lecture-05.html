Lecture content

CSS and its syntax

CSS (Cascading Style Sheets) controls how HTML looks. A rule has a selector and declarations, each written as a property and a value.

selector {
  property: value;
}

Inline, internal and external CSS

Inline

The style attribute on one element.

Internal

A style element inside the head of one page.

External

A separate .css file linked from each page, so one file styles the whole site.

Selectors

  • p element selector
  • .card class selector
  • nav a descendant: any a inside nav
  • ul > li child: li directly inside ul
  • h1 + p adjacent sibling
  • h1 ~ p general sibling

Pseudo-classes and pseudo-elements

Pseudo-class

Targets a state or condition, such as a:hover or li:first-child.

Pseudo-element

Targets a part of an element, such as ::before and ::after, which add generated content.

Cascade, specificity and inheritance

When several rules match, the cascade chooses one. More specific selectors win: inline style beats an ID, an ID beats a class, and a class beats an element. If specificity is equal, the later rule wins. Some properties, such as color and font-family, are inherited by child elements, and you can control this with inherit.

Colour, font, text and background

Colour

Names, HEX (#3b6bff), RGB and RGBA (with transparency).

Font

font-family with fallbacks (serif or sans-serif), font-size, font-weight, font-style.

Text

text-align, text-decoration, text-transform, line-height, letter-spacing.

Background

Colour, image, background-repeat, position, size, and the background shorthand.

Worked example

This rule styles a card, its links on hover, and adds a label before it.

.card {
  background: #f5f7fd;
  color: #141b3a;
  font-family: "Segoe UI", sans-serif;
}
.card a:hover { color: rebeccapurple; }
.card::before { content: "Tip: "; font-weight: bold; }

Quick check

Answer in your head first, then open the answer.

1. What is the difference between a pseudo-class and a pseudo-element?

A pseudo-class targets a state of an element. A pseudo-element targets a part of an element.

2. Why is external CSS useful?

One file can style every page of the site.

3. Two rules have equal specificity. Which wins?

The one written later.

Tips and common mistakes

Common mistake

Wondering why your rule has no effect? Another rule with higher specificity, or one that comes later, is probably overriding it.

Pro tip

Put your CSS in an external file and link it from every page, so one change updates the whole site.
