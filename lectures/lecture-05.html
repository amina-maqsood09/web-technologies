Lecture 5: CSS Basics, Selectors and Cascade

Selectors, pseudo-classes, the cascade and text styling

Summary

This lecture explains how CSS styles a page. You will learn the CSS syntax, three ways to add CSS, selectors, pseudo-classes and pseudo-elements, how the cascade, specificity and inheritance decide which rule wins, and the colour, font and text properties.

Topics Covered

  • CSS syntax
    • A rule has a selector and declarations (property: value)
  • Adding CSS
    • Inline, internal and external CSS
    • External CSS can style the whole site
  • Selectors
    • Element, class and ID selectors
    • Descendant, child and sibling selectors
  • Pseudo-classes and pseudo-elements
    • :hover, :focus and :first-child
    • ::before and ::after
  • Cascade, specificity and inheritance
    • More specific selectors win
    • If equal, the later rule wins
    • Some properties are inherited by children
  • Colour, font, text and background
    • Colour names, HEX and RGB
    • font-family, font-size and font-weight
    • text-align, text-decoration and line-height
    • background-color, image, repeat and size
Common Selectors
Selector Meaning Example
Element All elements of that type p
Class Elements with that class .note
ID The element with that ID #intro
Descendant Any element inside another nav a
Child Element directly inside another ul > li
Adjacent sibling Element right after another h1 + p

Example Code

This internal style sheet uses element, class, ID, pseudo-class and pseudo-element selectors.

<style>
  .demo5 p { color: navy; }
  .demo5 .note { color: green; }
  #intro { color: crimson; font-weight: bold; }
  .demo5 li:first-child { font-style: italic; }
  .demo5 a:hover { color: crimson; }
  .demo5 .tip::before { content: "Tip: "; font-weight: bold; }
</style>
<div class="demo5">
  <p>Element selector: navy.</p>
  <p class="note">Class selector: green.</p>
  <p id="intro" class="note">ID beats class.</p>
  <ul>
    <li>First item (first-child)</li>
    <li>Second item</li>
  </ul>
  <p><a href="#">Hover over this link</a></p>
  <p class="tip">Generated with ::before.</p>
</div>

Output

Element selector: navy.

Class selector: green.

ID beats class.

  • First item (first-child)
  • Second item

Hover over this link

Generated with ::before.
