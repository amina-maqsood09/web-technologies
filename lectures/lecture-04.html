Lecture 4: HTML5, Semantics and Forms

Block and inline elements, semantic HTML and forms

Summary

This lecture explains how to give a page meaning and how to collect user input. You will learn block and inline elements, semantic elements, forms and form controls, and HTML5 validation.

Topics Covered

  • Block and inline elements
    • Block elements start on a new line, inline elements stay on the line
    • div and span are generic containers
    • Use div and CSS for layout, and tables for data only
  • Semantic elements
    • header, nav, main, section, article, aside and footer
  • Forms
    • action and method (GET or POST)
    • label, input, select, textarea, button, fieldset and legend
    • Input types: text, email, password, number, date, radio, checkbox and file
  • Validation and accessibility
    • required, pattern, min and max
    • The server must still validate the data
    • Connect each label to its control with for and id
Semantic Elements
Element Purpose
header Introduction or branding
nav Navigation links
main Main content of the page
section A group of related content
article A self-contained item
aside Related side content
footer Ending information

Semantic Layout

This is how a page is organized with semantic elements.

<header>Site title and branding</header>
<nav>Menu links</nav>
<main>
  <section>
    <article>One self-contained item</article>
  </section>
  <aside>Related side content</aside>
</main>
<footer>Ending information</footer>

Example Code

A registration form with labels, validation rules, choices, a dropdown and a button.

<form action="#" method="post">
  <fieldset>
    <legend>Student Registration</legend>
    <p><label for="name">Name:</label>
       <input type="text" id="name" name="name" required></p>
    <p><label for="reg">Registration no.:</label>
       <input type="text" id="reg" name="reg"
              pattern="FA[0-9]{2}-BSE-[0-9]{3}"
              placeholder="FA24-BSE-019" required></p>
    <p><label for="age">Age:</label>
       <input type="number" id="age" name="age" min="16" max="60"></p>
    <p>Program:
       <input type="radio" id="bse" name="program" value="bse">
       <label for="bse">BSE</label>
       <input type="radio" id="bcs" name="program" value="bcs">
       <label for="bcs">BCS</label></p>
    <p>Skills:
       <input type="checkbox" id="html" name="skills" value="html">
       <label for="html">HTML</label>
       <input type="checkbox" id="css" name="skills" value="css">
       <label for="css">CSS</label></p>
    <p><label for="city">City:</label>
       <select id="city" name="city">
         <option>Vehari</option>
         <option>Islamabad</option>
       </select></p>
    <p><label for="msg">Message:</label><br>
       <textarea id="msg" name="msg" rows="3" cols="30"></textarea></p>
    <button type="submit">Register</button>
  </fieldset>
</form>
