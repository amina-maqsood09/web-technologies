Lecture content

HTML and the role of markup

HTML (HyperText Markup Language) is the most basic building block of the Web. It defines the meaning and structure of content. "Hyper" refers to hyperlinks, which let you jump from one page to another. Markup means annotating content with tags in angle brackets, usually in opening and closing pairs. HTML is not a programming language: it does not run logic, it only tells the browser what the content is.

HTML

Structure and meaning.

CSS

Appearance: colour, spacing, layout, typography.

JavaScript

Behaviour: validation, menus, dynamic updates.

Tag, element and attribute

Tag

The markup pieces, such as <p> and </p>.

Element

The complete unit, such as <p>Hello</p>.

Attribute

Extra information, such as href="..." or class="...".

Elements nest like a tree. Close them in reverse order: the last one opened is the first one closed. 

Correct: <p><strong>Important</strong></p>
Wrong:   <p><strong>Important</p></strong>

Validating your HTML

A validator checks your syntax against W3C standards. Use the W3C Markup Validator or the Nu HTML Checker: paste your code or upload the file, then fix the errors it reports, such as missing closing tags or invalid attributes. Validation helps your code work across browsers, catches errors early, and supports accessibility and SEO.

Headings, text and links

Use h1 to h6 to describe hierarchy, and use CSS to change how large text looks. Text can also carry meaning:

  • <strong> importance
  • <em> emphasis
  • <mark> highlight
  • <del> / <ins> removed / added
  • <br> / <hr> line break / divider

Absolute link

https://example.com is a full address.

Relative link

about.html points to a file in the same site.

Fragment link

#contact jumps to a place in the same page.

Images, audio and video

An image needs a src (where it comes from) and an alt (a text alternative for accessibility). You can also set a width. Audio and video use <audio controls> and <video controls> with a <source> inside. Captions and transcripts make media more inclusive.

Lists

ul

Unordered list, with li items.

ol

Ordered (numbered) list.

dl

Description list: dt terms with dd definitions, like a glossary.

Tables

Tables are for data that has relationships. A professional table has clear regions:

  • caption what the table is about
  • thead column headers
  • tbody main data
  • tfoot summary or totals

Use colspan to merge cells across columns and rowspan to merge across rows. The older attributes border, cellpadding and cellspacing exist, but styling belongs in CSS. Do not use tables just to lay out a page.

Key features of HTML5

Responsive design

Pages adjust to the screen size. The viewport meta tag makes them scale correctly.

Native multimedia

Audio and video work without plugins such as Flash.

Canvas

Draw graphics, animations or games with JavaScript.

New input types

email, tel and date adapt to the device. A tel field opens a numeric keypad on a phone.

Storage

localStorage keeps data with no expiry. sessionStorage keeps it for the session.

Offline support

localStorage and service workers let web apps work without a connection.

HTML5 is widely supported in modern browsers: Chrome, Firefox, Safari and Edge handle semantic elements, audio, video and canvas well.

Worked example: a basic page

Every HTML page follows a predictable structure: a DOCTYPE, then html containing a head and a body.

<!DOCTYPE html>
<html lang="en">
<head>
  <meta charset="UTF-8">
  <title>My First Page</title>
</head>
<body>
  <h1>Web Technologies</h1>
  <p>HTML structures web content.</p>
</body>
</html>

Quick check

Answer in your head first, then open the answer.

1. What is the difference between a tag and an element?

A tag is a single markup piece like <p>. An element is the complete unit: the opening tag, the content and the closing tag.

2. Why is HTML not a programming language?

It does not run logic or calculations. It only tells the browser what the content is.

3. Why does an image need an alt attribute?

It gives a text alternative, which is important for accessibility.

4. When should you use a table?

For data with relationships, such as marks or a timetable, not for page layout.

Tips and common mistakes

Common mistake

Choosing a heading level because of its size. Use heading levels for hierarchy and change the size with CSS.

Pro tip

Run your page through the validator before you submit. Most beginner bugs, like missing closing tags, show up immediately.
