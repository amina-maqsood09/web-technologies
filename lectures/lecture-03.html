Lecture 3: HTML Structure and Content

Structure, text, links, lists and tables

Summary

This lecture explains how an HTML document is built. You will learn tags, elements and attributes, how to nest elements correctly, how to validate your code, and how to add text, links, images, lists and tables.

Topics Covered

  • HTML basics
    • HTML gives structure and meaning to content
    • CSS controls appearance and JavaScript controls behaviour
  • Document structure
    • DOCTYPE, html, head and body
    • Tag, element and attribute
    • Elements are nested and closed in reverse order
  • Validation
    • The W3C validator checks your code for errors
  • Content
    • Headings h1 to h6, paragraphs and text formatting
    • Links: absolute, relative and fragment
    • Images with src and alt, audio and video
  • Lists and tables
    • ul, ol and dl lists
    • caption, thead, tbody and tfoot
    • colspan and rowspan
  • HTML5 features
    • Responsive design, native audio and video, canvas, new input types, localStorage
Common HTML Elements
Element Purpose Example
h1 to h6 Headings <h1>Title</h1>
p Paragraph <p>Text</p>
a Link <a href="page.html">Open</a>
img Image <img src="a.png" alt="Logo">
ul / ol Unordered and ordered lists <ul><li>Item</li></ul>
table Data in rows and columns <table>...</table>

Example Code

This code uses headings, text formatting, lists, a link and a table with colspan.

<h3>My Course Notes</h3>
<p>This is <strong>important</strong> and this is <em>emphasized</em>.</p>
<ul>
  <li>HTML</li>
  <li>CSS</li>
</ul>
<ol>
  <li>Learn</li>
  <li>Practice</li>
</ol>
<p>Visit the <a href="https://validator.w3.org/">W3C Validator</a>.</p>
<table>
  <caption>Marks</caption>
  <thead>
    <tr><th>Name</th><th>Marks</th></tr>
  </thead>
  <tbody>
    <tr><td>Ali</td><td>85</td></tr>
    <tr><td>Sara</td><td>91</td></tr>
  </tbody>
  <tfoot>
    <tr><td colspan="2">Total: 2 students</td></tr>
  </tfoot>
</table>
