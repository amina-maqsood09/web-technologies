Lecture 1: The Web and How It Works

The Internet, the Web and what happens when you open a page

Summary

This lecture explains the difference between the Internet and the Web, what you need to create and publish a website, how a browser and a server talk to each other, and how HTML developed over time.

Topics Covered

  • Internet and Web
    • The Internet is the global network of computers
    • The Web is a system of linked pages that runs on the Internet
  • Creating a website
    • Text editor, upload tool, hosting service and browser
    • Publishing means uploading a page to a web server
  • How the Web works
    • Browser (client) sends a request, server sends a response
    • URL, DNS, HTTP and HTTPS
  • Standards and history
    • W3C, WHATWG, ECMA and IETF
    • HTML from 1989 to HTML5
  • Types of web applications
    • Static, dynamic, MPA, SPA and PWA

What Happens When You Open a Page

  1. You type a URL in the browser.
  2. The browser asks DNS for the IP address of the domain name.
  3. The browser sends an HTTP request to the web server.
  4. The server processes the request and sends back an HTTP response.
  5. The browser shows (renders) the page.

Parts of a URL

For example, https://www.example.com:443/courses/web?id=101#http has these parts:

  • https:// is the scheme (protocol)
  • www.example.com is the domain name
  • :443 is the port
  • /courses/web is the path
  • ?id=101 is the query
  • #http is the fragment
Common HTTP Methods

History of HTML
Year Event
1989 Tim Berners-Lee proposes hypertext links at CERN
1994 The W3C is founded
1997 HTML4 is released
2001 XHTML 1.1 is too strict and is mostly avoided
2004 WHATWG is formed
2009 W3C drops XHTML 2.0 and works with WHATWG
2011 The HTML5 logo appears
2017 HTML 5.1 becomes a W3C recommendation
